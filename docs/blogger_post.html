Windows 7 SP1 ~ 11 26H2 · 무료 오픈소스 포터블 유틸리티

AhBiShare OneClick v1.3.1 — Windows 7~11 원클릭 공유폴더 · 자료 자동 백업 · 사용장소 프로필 유틸리티

프로그램 소개

AhBiShare OneClick은 복잡한 Windows 네트워크 공유 설정 없이 클릭 한 번으로 폴더 공유 개설(메인 PC), 네트워크 드라이브 연결(클라이언트 PC), 사용장소별(사무실·집·현장) 프로필 일괄 적용, Windows 10·11 정책 불일치 자동 정렬, 그리고 Windows 7·8·8.1 구형 OS 호환 브릿지 및 오프라인 스크립트 생성까지 일괄 처리하는 무료 오픈소스 유틸리티입니다.

USB 메모리에 담아 무설치로 휴대 실행할 수 있으며, 모든 계정 비밀번호와 위치 프로필은 AES-256-GCM 암호화로 안전하게 보호됩니다. 최신 v1.3.0에서는 앱 실행 폴더 하위 backup 폴더를 통한 자동·수동 암호화 백업 및 원클릭 시점 복원 시스템이 새롭게 탑재되었습니다.

  • 원클릭 공유폴더 개설 & 네트워크 드라이브 연결: 권한·방화벽 TCP 445·ABSHARE:// 연결 코드 및 QR 발급, ActiveShare 탐색기(UNC) 바로 열기 지원
  • 자료 자동 백업 & 시점 복원 (v1.3.0 신규): 포터블 설정·사용장소 프로필·오류 티켓 전체를 backup 하위 폴더에 AES-256-GCM 암호화 저장(최대 20개 회전 보관)
  • 스마트 SMB 인증 감지 & USB 양방향 해결 마법사: 무비밀번호/보안 계정 자동 판별, 호스트-클라이언트 간 USB 이동 시 일치 오류 티켓 자동 감지 및 3단계 마법사 복구
  • 구형 OS(Win 7·8·8.1 ⇄ Win 10·11) 완벽 호환: 2단계 통합 브릿지, 순정 Win 7 오프라인 .bat/.reg 키트 생성 및 포터블 자가 교체 업데이트

  • SemVer 동적 검증 & 패치 노트·공식 문서 자동 동기화 (v1.3.1): docs/PATCH_NOTES.md 최신 변경 내역 섹션 자동 기록, docs/blogger_post.html·docs/README.md·릴리즈 문서 일괄 버전 동기화, .gitignore 백업/로그 제외 규칙 및 15대 무결성 검증 스위트 동적 버전 일치 검증을 정비했습니다.
  • 앱 하위 backup 폴더 자동 생성 및 전체 자료 AES-256-GCM 암호화 백업: 실행 폴더 하위 backup 디렉터리에 포터블 설정(.portable.json), 사용장소 프로필(.location.json), USB 오류 티켓(troubleshootTickets) 전체를 기존 AES-256-GCM 암호화 상태로 안전하게 스냅샷 저장합니다.
  • 삭제·변경·초기화·복원 직전 자동 안전 백업 & 20개 회전 보관: 데이터 변경·삭제·초기화·복원 실행 직전 자동으로 안전 백업을 생성(동일 내용 해시 중복 스킵)하며, 최근 20개 스냅샷(BACKUP_MAX_SNAPSHOTS = 20)을 자동 회전 보관해 용량 과다 누적을 방지합니다.
  • 전용 백업·복원 모달(BackupRestoreModal) & 원클릭 시점 복원: 백업 목록 조회, 트리거별 필터·검색, 수동 백업 메모 생성, 원클릭 시점 복원(복원 전 안전 백업 선행), 개별 스냅샷 삭제 및 백업 폴더 바로 열기를 지원합니다.
  • 상단 바 & 실행 이력 화면 백업 단축 버튼 연동: 상단 바(TopBar)의 백업·복원 버튼과 실행 이력 화면의 백업 관리 단축 버튼으로 언제든 즉시 복구 창에 접근할 수 있습니다.
  • OS 호환성 매트릭스 ↔ USB 해결 마법사 양방향 동기화(SyncAwarePolicyBadge): 로컬 OS 정책 상태(policyStatus)를 실시간 비교해 이미 시스템 패치로 충족된 마법사 단계는 Policy Matched 배지와 함께 자동으로 완료·건너뛰기 처리하며, 재부팅·대기 작업을 매트릭스와 마법사 간 일관되게 동기화합니다.
