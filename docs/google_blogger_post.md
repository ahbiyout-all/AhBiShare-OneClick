# AhBiShare OneClick v1.0.0 — Windows 7~11 원클릭 공유폴더 & 구형 OS 호환 유틸리티

## 본문
**AhBiShare OneClick**은 Windows PC 간 공유폴더 개설(메인 PC), 네트워크 드라이브 연결(클라이언트 PC), Windows 10·11 간 보안 정책 불일치 자동 정렬, 그리고 Windows 7·8·8.1 구형 OS 호환 브릿지 및 오프라인 스크립트 생성을 클릭 한 번으로 해결하는 무료 유틸리티입니다.

## 업데이트
- **원클릭 공유 개설 및 연결**: 방화벽 TCP 445·139 개방, 무비밀번호 게스트 및 보안 계정 모드 지원, `ABSHARE://` 연결 코드·QR 코드 발급
- **구형 OS 공유 (Win 7·8·8.1 ⇄ Win 10·11)**: 1단계 메인·2단계 클라이언트 통합 원클릭, 2단계 SMB 1.0 확인, USB 오프라인 4종(`.bat`/`.reg`) 키트 및 양방향 JSON 데이터 브릿지
- **표준 / 용량 감소 Lite / Win 7 전용 빌드 제공**: 경량 압축 Lite 버전 및 Windows 7 SP1~8.1 직접 실행 빌드 지원
- **Inno Setup 설치 및 자동 업데이트**: 방화벽 자동 등록·무인 설치 지원 및 GitHub Releases 실시간 업데이트 알림 팝업
